# JLPT N4 한자 암기장 (v4)

다락원 『JLPT 한권으로 끝내기 N4』 문자·어휘 파트를 바탕으로 만든 한자 중심 학습 앱입니다.
빌드 과정 없이 GitHub Pages에 파일을 올리기만 하면 동작합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 틀 |
| `style.css` | 디자인 (밝은/어두운 테마 자동 전환) |
| `app.js` | 앱 동작 (React 없이 순수 JavaScript) |
| `data.js` | 한자 321자 · 어휘 1,195개 · 유의표현 220개 · 기출 1,089문항 |
| `tools/` | 데이터 재생성 도구 (교재 내용을 고칠 때만 사용) |
| `legacy/` | 이전 버전(v3) 파일 보관 |

## GitHub Pages에 올리는 방법

1. 저장소(예: `JLPT4-`)에 위 파일들을 그대로 올립니다. 기존 `index.html`은 덮어씁니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 에서 열립니다.

같은 주소에 올리면 이전 버전 앱의 오답 기록을 처음 실행할 때 자동으로 가져옵니다.

## 메뉴 구성

- **오늘** — 오늘 복습할 한자·어휘와 새 한자를 한 번에 학습 (간격 반복: 모름 → 10분 뒤, 애매 → 내일, 앎 → 1·3·7·14·30일), 시험 D-day, 레벨별 암기 현황
- **한자** — N5 · N4 · 기출 N3 한자 목록, 원고지 칸에 손글씨체로 보여 주는 상세 화면(훈음 · 음독 · 훈독 · 모양 힌트 · 들어간 단어 · 닮은 한자), 카드 학습과 4종 퀴즈
- **어휘** — 1~15과 단어 카드, 뜻·읽기·표기 퀴즈, 통합 검색
- **문제** — 기출 확인문제 131세트, 유형별 랜덤 20문항, 5유형 실전 모의 25문항
- **오답** — 틀린 한자·어휘·문제를 모아 다시 학습 (맞히면 자동으로 빠짐)

## 음성 지원

브라우저 내장 일본어 음성(Web Speech API)을 사용합니다. 별도 설정 없이 동작합니다.

- **읽기 정확도 검증**: 브라우저 음성은 한자를 스스로 읽기 때문에 틀리게 읽을 수 있습니다(예: 開く를 ひらく, 明日를 あした, 行って를 おこなって, 日本을 にっぽん).
  그래서 빌드할 때 형태소 분석기(kuromoji)로 모든 단어·문장을 미리 읽어 보고, 교재 읽기와 다른 61곳은 히라가나로 바꿔 읽히도록 했습니다. 결과는 `tools/speech_report.txt`에 있습니다.
- **음질**: 기기에 있는 일본어 음성 중 고음질(신경망·Enhanced·Google) 음성을 자동으로 고릅니다. 설정에서 직접 고를 수도 있습니다.
- **또박또박 듣기**: 단어는 문장보다 느리게 읽고, 🔊 버튼을 3초 안에 다시 누르면 0.6배 속도로 다시 읽습니다.
- 한자읽기 문제는 정답이 드러나지 않도록 **채점 후에만** 정답을 넣은 문장을 읽어 줍니다.

더 좋은 음성을 쓰려면 기기에 고음질 일본어 음성을 설치하세요.
- iPhone·iPad: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 일본어 → Kyoko(고품질) 다운로드
- Android: 설정 → 텍스트 음성 변환 → Google 음성 엔진 → 일본어 음성 데이터 설치
- PC: Microsoft Edge로 열면 Nanami(자연스러운 음성)를 사용할 수 있습니다.

## v3 대비 바뀐 점

**학습 구조**
- 한자 DB를 183개(중복 10개 포함)에서 N5·N4 전체 + 기출 N3 한자 321자로 확장하고, 모든 한자에 한국식 훈음·음독(가타카나)·훈독(오쿠리가나 구분)을 정리했습니다.
- 과별로 흩어져 있던 어휘 1,778줄을 중복 없이 1,195개로 통합하고, 각 단어가 나오는 과를 표시합니다.
- 단어 퀴즈의 오답 보기를 실제 시험처럼 만듭니다. 읽기 문제는 탁음·장음·촉음·요음을 바꾼 함정, 표기 문제는 모양이 닮은 한자와 같은 읽기의 다른 한자를 보기로 냅니다.
- 문제는 한 화면에 한 문항씩, 후리가나 표시 여부를 선택할 수 있고, 타이머(문항당 20초)를 켤 수 있습니다.

**데이터 오류 수정**
- 한자 DB의 잘못된 훈독 수정: 研(けん→と.ぐ), 勉·院·特·発·駅·台·部·料·意·紹(음독을 훈독으로 잘못 넣음→훈독 없음), 練(れん→ね.る) 등
- 음독을 히라가나에서 가타카나로 통일
- 자형 설명 오류 수정: 近(走+斤→辶+斤), 姉(女+兄→女+市), 青, 早, 冬, 走, 帰, 急 등
- 3과 확인문제 18~25의 오답 보기 해설 중 엉뚱한 단어를 가리키던 것(예: 食事 문제에 '청소의 오독') 30여 건을 바로잡고,
  한자읽기 문제의 모든 오답 보기에 「장음 차이」「탁음 차이」처럼 무엇이 틀렸는지 자동 분석한 설명을 붙였습니다.
- 1과 1번 보기의 잘못된 해설(おねさん '어니살', おにさん '오빠/형')을 수정했습니다.
- 13·14과 퀴즈에서 한자와 히라가나 위치가 뒤바뀌어 나오던 문제를 고쳤습니다.
- 한자읽기 문제 중 밑줄 정답 위에 후리가나가 붙어 정답이 화면에 보이던 5문항(銀行·寒い·赤い·近く 등)을 고쳤습니다.
- 밑줄 범위가 보기와 맞지 않던 3문항(楽しそうに·動き·何度)과 어휘 오타 「利由」(→ 理由)를 바로잡았습니다.
- 15과 용법 문제 「ニュース」 보기 해설 「(메뉴?)」를 「메뉴가 많다 = メニューが 多い」로 정리했습니다.

## 데이터를 고칠 때

`tools/kanji_table.txt`(한자 표)나 `tools/build_data.js`(교정 목록)를 고친 뒤 아래를 실행하면 `data.js`가 다시 만들어집니다.

```
cd tools
npm install      # 처음 한 번 (형태소 분석기 설치)
node build_data.js
```

학습 기록은 브라우저(localStorage)에만 저장됩니다. 다른 기기로 옮길 때는 **설정 → 학습 기록 백업**에서 복사·붙여넣기를 사용하세요.
