# JLPT N4 한자 암기장 (v4)

다락원 『JLPT 한권으로 끝내기 N4』 문자·어휘 파트를 바탕으로 만든 한자 중심 학습 앱입니다.
빌드 과정 없이 GitHub Pages에 파일을 올리기만 하면 동작합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 틀 |
| `style.css` | 디자인 (밝은/어두운 테마 자동 전환) |
| `app.js` | 앱 동작 (React 없이 순수 JavaScript) |
| `data.js` | 한자 686자 · 어휘 1,195개 · 유의표현 220개 · 기출 1,089문항 |
| `tools/` | 데이터 재생성 도구 (교재 내용을 고칠 때만 사용) |
| `legacy/` | 이전 버전(v3) 파일 보관 |

## GitHub Pages에 올리는 방법

1. 저장소(예: `JLPT4-`)에 위 파일들을 그대로 올립니다. 기존 `index.html`은 덮어씁니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 에서 열립니다.

같은 주소에 올리면 이전 버전 앱의 오답 기록을 처음 실행할 때 자동으로 가져옵니다.

## 메뉴 구성

- **오늘** — 오늘 복습할 한자·어휘와 새 한자를 한 번에 학습 (간격 반복: 모름 → 10분 뒤, 애매 → 내일, 앎 → 1·3·7·14·30일), 시험 D-day, 레벨별 암기 현황
- **일정** — 시험(12/6)까지 30회로 앱 전체를 끝내는 완주 코스. 공부 요일을 고르면 회차별 날짜가 자동 배치되고, 하루 빠지면 남은 회차가 뒤로 밀리며 시험 전 완주 가능 여부를 알려 줍니다.
  - 1~26회 데일리 챕터(약 1시간): 복습 → 새 한자 26자 안팎 → 훈음 확인 10문항 → 어휘 55개 안팎 → 기출 40문항 안팎
  - 27~30회: 실전 모의 25문항 + 유형 집중 20문항 + 닮은 한자 · 틀린 기출 · 오답 카드
  - 단계를 끝까지 마치면 자동 체크, 모든 단계를 마치면 회차 완료. 60분 집중 타이머 제공
  - 설정 → 학습 방식에서 「자유 학습」으로 바꾸면 이전처럼 하루 새 한자 수 방식으로 학습합니다.
- **한자** — N5(103) · N4(181) · 기출 N3(37) · 교재 등장(365) 한자 목록, 원고지 칸에 손글씨체로 보여 주는 상세 화면(훈음 · 음독 · 훈독 · 모양 힌트 · 들어간 단어 · 닮은 한자), 카드 학습과 4종 퀴즈
- **주제별로 묶어서** (오늘 화면 아래) — 요일 · 숫자·돈 · 날짜·시간 · 방향·위치 · 신체 · 가족·사람 · 자연·날씨 · 계절·색 · 이동·교통 · 학교·공부 · 반대말 형용사 · 기본 동사 · 장소·건물 · 음식, 14개 주제 203항목.
  한자마다 대표 단어(읽기·뜻·음성)를 붙였고, 주제별 카드와 퀴즈(같은 주제의 한자끼리 보기를 구성해 目·耳·口처럼 비슷한 것 사이에서 구별)를 제공합니다. 목록은 `tools/themes.txt`에서 고칠 수 있습니다.
- **어휘** — 1~15과 단어 카드, 뜻·읽기·표기 퀴즈, 통합 검색
- **문제** — 기출 확인문제 131세트, 유형별 랜덤 20문항, 5유형 실전 모의 25문항
- **오답** — 틀린 한자·어휘·문제를 모아 다시 학습 (맞히면 자동으로 빠짐)

## 무작위 출제

- 기출 확인문제, 데일리 챕터, 다시 풀기 모두 **문항 순서와 보기 순서를 매번 새로 섞습니다.** 정답 번호로 외우는 것을 막기 위해서입니다.
- 실전 모의와 유형 랜덤은 **아직 안 푼 문제 → 오래전에 푼 문제** 순으로 골라, 같은 문제가 반복해서 나오지 않게 합니다.
- 데일리 챕터의 새 한자·어휘 카드도 순서를 섞어 냅니다.

## 청해 듣기 (문제 탭 맨 위)

교재 『한권으로 끝내기 N4』 청해 음원을 한 문제씩 듣고, 정답과 **한국어 해설을 음성으로** 들을 수 있습니다.

- 문제 유형 공략하기 60문제 + 모의테스트 2회 + 온라인 모의 2회 = 172문제 (청해 요령 트랙과 유형 설명 트랙은 제외)
- 문제3·4(발화 표현·즉시 응답)는 1~3번을 골라 바로 채점, 문제1·2는 보기가 교재 그림·글자라서 정답 내용을 보여 주고 스스로 채점
- 일본어 스크립트: 줄을 누르면 그 부분부터 다시 재생, 재생 속도 0.8~1.2배
- **연속 듣기(자동 재생)**: 전체·회차별·문제 유형별로 문제 음성을 3·5·10초 간격으로 쭉 재생 (차례대로/섞어서, 속도 조절). 간격에도 무음 오디오를 재생해 휴대폰 화면이 꺼져도 이어지고, 잠금 화면의 ⏮ ⏭로 넘길 수 있음. 들은 위치를 기억해 다음에 이어서 재생
- 진행 상황(맞힘·틀림)은 번호 칸 색으로 표시, 「이어 듣기」「무작위 한 문제」

**음원은 이 저장소에 없습니다.** 교재 음원은 저작물이라 공개 저장소에 올리지 않고, 청해 팩 zip 3개(`N4_listening_1~3.zip`, 용량을 줄인 mp3 172개 + `n4-listening.json`)을 기기마다 한 번 불러와 브라우저 저장소(IndexedDB)에 넣어 씁니다.
해설과 스크립트는 음원을 음성 인식(Whisper)으로 받아 적은 뒤 손으로 고친 것이라, 일부 표현이 실제 음성과 다를 수 있습니다.

## 음성 지원

브라우저 내장 일본어 음성(Web Speech API)을 사용합니다. 별도 설정 없이 동작합니다.

- **읽기 정확도 검증**: 브라우저 음성은 한자를 스스로 읽기 때문에 틀리게 읽을 수 있습니다(예: 開く를 ひらく, 明日를 あした, 行って를 おこなって, 日本을 にっぽん).
  그래서 빌드할 때 형태소 분석기(kuromoji)로 모든 단어·문장을 미리 읽어 보고, 교재 읽기와 다른 61곳은 히라가나로 바꿔 읽히도록 했습니다. 결과는 `tools/speech_report.txt`에 있습니다.
- **2차 검수(v4.3)**: 기계가 틀리기 쉬운 읽기를 히라가나로 고정했습니다 — 日本→にほん, 단독 家→いえ(今家·先月家를 「か」로 읽던 문제), 音→おと, この方→かた, 一日→いちにち, 週に2日→ふつか (53곳).
  대화문의 화자 표시(A「 B「), 「~」「/」, 숫자 쉼표, 반각 ?! 같이 기계가 그대로 읽거나 끊어 읽던 기호를 정리했고, 검증이 없던 유의표현 220개 문장도 같은 검수를 거칩니다.
  교재 후리가나 오류 「ドアを引いて開(ひら)けました」→ あけました 를 바로잡았습니다.
- **재생 방식**: 정답을 고르거나 카드를 뒤집어도 자동으로 읽지 않고, 🔊 버튼을 눌렀을 때만 읽습니다(설정 → 자동 재생으로 다시 켤 수 있음). 재생 중 다시 누르면 앞 소리를 정리한 뒤 읽어 소리가 뭉개지지 않게 했고, 크롬에서 긴 문장이 중간에 끊기는 현상을 막았습니다.
- **음질**: 기기에 있는 일본어 음성 중 고음질(신경망·Enhanced·Google) 음성을 자동으로 고릅니다. 설정에서 직접 고를 수도 있습니다.
- **또박또박 듣기**: 단어는 문장보다 느리게 읽고, 🔊 버튼을 3초 안에 다시 누르면 0.6배 속도로 다시 읽습니다.
- **보기마다 🔊**: 채점 후 각 보기 옆의 버튼으로 오답 보기의 발음도 들을 수 있습니다(장음·탁음 함정 비교). 표기 문제의 틀린 한자 조합처럼 실제로 없는 말은 제외합니다.
- 문맥규정 문제는 빈칸을 잠깐 쉬는 소리로 바꿔 풀기 전에도 문장을 들려 줍니다. 틀린 문제 다시 보기, 오답노트, 같은 읽기 다른 한자 목록에도 음성을 넣었습니다.
- 한자읽기 문제는 정답이 드러나지 않도록 **채점 후에만** 정답을 넣은 문장을 읽어 줍니다.

더 좋은 음성을 쓰려면 기기에 고음질 일본어 음성을 설치하세요.
- iPhone·iPad: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 일본어 → Kyoko(고품질) 다운로드
- Android: 설정 → 텍스트 음성 변환 → Google 음성 엔진 → 일본어 음성 데이터 설치
- PC: Microsoft Edge로 열면 Nanami(자연스러운 음성)를 사용할 수 있습니다.

## v3 대비 바뀐 점

**학습 구조**
- 한자 DB를 183개(중복 10개 포함)에서 N5·N4 전체 + 기출 N3 한자 321자로 확장하고, 교재 어휘에 나오는 나머지 한자 365자를 「교재 등장」 단계로 더해 모두 686자가 되었습니다(교재 어휘에 쓰인 한자는 하나도 빠짐없이 들어 있음).
  「교재 등장」 한자는 N4 필수 범위 밖이라 빠른 퀴즈에는 섞이지 않고, 오늘 학습에서는 N5·N4·기출 321자를 모두 시작한 뒤에 차례로 나옵니다. 한자 탭에서 바로 골라 공부할 수도 있습니다. 田舎·景色·真面目·息子처럼 특별한 읽기가 있는 한자에는 힌트를 달았습니다.
- 모든 한자에 한국식 훈음·음독(가타카나)·훈독(오쿠리가나 구분)을 정리했습니다.
- 과별로 흩어져 있던 어휘 1,778줄을 중복 없이 1,195개로 통합하고, 각 단어가 나오는 과를 표시합니다.
- 단어 퀴즈의 오답 보기를 실제 시험처럼 만듭니다. 읽기 문제는 탁음·장음·촉음·요음을 바꾼 함정, 표기 문제는 모양이 닮은 한자와 같은 읽기의 다른 한자를 보기로 냅니다.
- 문제는 한 화면에 한 문항씩, 후리가나 표시 여부를 선택할 수 있고, 타이머(문항당 20초)를 켤 수 있습니다.

**데이터 오류 수정**
- 한자 DB의 잘못된 훈독 수정: 研(けん→と.ぐ), 勉·院·特·発·駅·台·部·料·意·紹(음독을 훈독으로 잘못 넣음→훈독 없음), 練(れん→ね.る) 등
- 음독을 히라가나에서 가타카나로 통일
- 자형 설명 오류 수정: 近(走+斤→辶+斤), 姉(女+兄→女+市), 青, 早, 冬, 走, 帰, 急 등
- 3과 확인문제 18~25의 오답 보기 해설 중 엉뚱한 단어를 가리키던 것(예: 食事 문제에 '청소의 오독') 30여 건을 바로잡고,
  한자읽기 문제의 모든 오답 보기에 「장음 차이」「탁음 차이」처럼 무엇이 틀렸는지 자동 분석한 설명을 붙였습니다.
- 1과 1번 보기의 잘못된 해설(おねさん '어니살', おにさん '오빠/형')을 수정했습니다.
- 13·14과 퀴즈에서 한자와 히라가나 위치가 뒤바뀌어 나오던 문제를 고쳤습니다.
- 한자읽기 문제 중 밑줄 정답 위에 후리가나가 붙어 정답이 화면에 보이던 5문항(銀行·寒い·赤い·近く 등)을 고쳤습니다.
- 밑줄 범위가 보기와 맞지 않던 3문항(楽しそうに·動き·何度)과 어휘 오타 「利由」(→ 理由)를 바로잡았습니다.
- 15과 용법 문제 「ニュース」 보기 해설 「(메뉴?)」를 「메뉴가 많다 = メニューが 多い」로 정리했습니다.

- 일본어 문장이 띄어쓰기 단위로만 줄바꿈되어 문제 상자 밖으로 넘치던 현상(화면 폭 360px에서 64곳)을 글자 단위 줄바꿈으로 고쳤습니다. 줄 첫머리에 っ·ゃ·。가 오지 않도록 일본어 줄바꿈 규칙을 적용했습니다.

## 데이터를 고칠 때

`tools/kanji_table.txt`(한자 표)나 `tools/build_data.js`(교정 목록)를 고친 뒤 아래를 실행하면 `data.js`가 다시 만들어집니다.

```
cd tools
npm install      # 처음 한 번 (형태소 분석기 설치)
node build_data.js
```

학습 기록은 브라우저(localStorage)에만 저장됩니다. 다른 기기로 옮길 때는 **설정 → 학습 기록 백업**에서 복사·붙여넣기를 사용하세요.
